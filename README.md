# 对话增强 1.7.0

参考 MiniMax Code 的原位选文评论方式，专注提供高质量的原位批注与原生引用卡片支持。

## 功能

### 1. 选文原位评论与引用
选中消息中的任意文字 → 浮条“加入本会话” → 直接填写评论 → 点 ✓ 保存。原文和批注进入 DSH **原生引用卡片**，无需再点“放入草稿”。你仍使用原来的发送按钮发送；插件不会自动发消息。

只引用无需评论：浮条点“引用”。

### 2. 回复动作栏批注
已完成的 AI 回复动作栏提供“引用 / 批注回复”，保存后的引用卡片由宿主负责预览、移除、草稿恢复与提交，提交内容明确区分“引用原文”和“我的批注”。可连续对多个片段批注。

### 3. 旧版未发送批注恢复
若本地存在历史版本残留的未发送草稿，输入框左侧会露出轻量的“恢复旧版未发送批注”按钮，可一键将其转为原生卡片。

---

> 注：关于回合中断与发送，完全交还 DSH 宿主原生处理（原生停止生成键与发送键），不再进行任何模拟“发一条继续”或 DOM 劫持。

## 开发

`npm run build` 构建浏览器单文件并检查语法；`npm test` 运行测试；`npm run package` 生成带版本安装包。无需外部依赖或安装脚本。当前为工作区目录链接安装，不要移动其源码目录。

> 浏览器端改动**必须重启应用**才生效；插件热更新只在进程内第一次加载时可靠。
